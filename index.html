Multi-Switch Array

The logic is now fully procedural. The fabric has been extended horizontally to incorporate an array of independent tuck-stitch contact zones.

The Mechanics: Stretching the fabric horizontally activates all three switches simultaneously. The physics engine dynamically calculates the deformation mesh based on the distance to the nearest orange tuck stitch.
